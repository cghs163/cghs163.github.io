在本机写好 Markdown，预览满意后推送到 GitHub，Actions 会自动构建并发布到 GitHub Pages。

## 日常三步

在项目根目录先加载环境（新开终端时执行一次）：

```powershell
. .\tools\env.ps1
```

然后：

1. **新建文章**：`npm run new -- "文章标题"`
2. **本地预览**：`npm run server`，浏览器打开 `http://localhost:4000`
3. **发布上线**：`npm run deploy`（提交并推送到 `main`，触发 GitHub Actions）

## 文章写在哪里

新建后的文件在 `source/_posts/` 目录。Front-matter 示例：

```yaml
---
title: 文章标题
date: 2026-03-26 22:35:00
tags:
  - 标签
categories:
  - 分类
---
```

改完保存，本地预览会热更新；确认无误再 `npm run deploy` 即可。
